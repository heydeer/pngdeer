Research

The best open-source PNG compressor we've measured.

We ran pngdeer, TinyPNG and eight open-source quantizers on 180 PNGs: icons, UI screenshots, illustrations, photos, cut-outs and 3D renders. Every output was scored with SSIMULACRA2, a perceptual metric where 90 means indistinguishable at 1:1.

How it works

Every palette size, judged like an eye would.

01

Searches the palette

pngdeer tries palette sizes from 2 to 256 colors, with and without dithering, and keeps the smallest file that still reaches the quality.

indistinguishable
05090
02

Scores what you'd see

Quality is SSIMULACRA2, measured in-process. Colors are matched in Oklab, and transparent pixels are judged over light and dark backgrounds.

03

Stays on your device

The compressor is WebAssembly, using every core. Your images never leave the browser, and the command line writes the same bytes.

Command line

Same bytes in your build.

The browser and the command line run the same Rust code, down to the math library, so a file compressed here and in your pipeline comes out identical.

Pass --target 85 for a fixed quality instead of the automatic one.

$ brew install heydeer/tap/pngdeer $ pngdeer kodim01.png -o kodim01.min.png {"target": 86.26, "colors": 212, "variant": "d50", "score": 87.271, …, "outcome": "hit", "bytes": 254373}
